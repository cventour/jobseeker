JobSeeker Bridge

Lets the JobSeeker dashboard running on this computer read WhatsApp Web, LinkedIn and careers pages in this Chrome. Nothing leaves this computer, and it can only read; it never types, clicks or submits anything.

Pair with the dashboard

In the JobSeeker dashboard, open Settings, then Browser, then Connect. It shows a six-digit code. Type it here.

Careers pages

Out of the box the bridge can read only WhatsApp Web and LinkedIn. To let JobSeeker also read job postings on company careers sites, allow it to read any site. This is read-only, and you can take it back at any time from chrome://extensions.

Forget pairing

Removes the pairing token from this Chrome. The dashboard will show a new code the next time you connect.
