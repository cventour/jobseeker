# Application answer library (example)

Copy to `templates/answers.md` (gitignored) and fill in. The application-agent reuses these
for common application-form questions so it doesn't re-improvise each time. Anything it can't
map to an answer here becomes an approval checkpoint.

| question_pattern | answer |
|------------------|--------|
| work authorization / visa | e.g. "Authorized to work in the UAE" |
| notice period | e.g. "1 month" |
| salary expectation | e.g. "Open / competitive — happy to discuss" |
| years of experience | e.g. "12" |
| willing to relocate | e.g. "Yes, to Dubai" |
| how did you hear about us | e.g. "LinkedIn" |

Free-text elevator pitch (reused for "why do you want to work here" style prompts):

> Two or three sentences about your focus and what you're looking for.
