Install

Two commands,
then one click.

Setup checks what you have, installs what it can, and verifies each permission actually worked rather than assuming it did.

You need

  • A Mac. JobSeeker drives macOS and is not portable to Windows or Linux.
  • Google Chrome, logged in to the accounts you want read.
  • Node 20 or newer.
  • Claude Code — the agents run inside it.

Install

git clone https://github.com/cventour/jobseeker
cd jobseeker
npm run setup

There is nothing to npm install. The whole system runs on Node built-ins and shell, so there are no dependencies to audit and nothing to rot.

Then

claude
> /onboard

Onboarding asks what you are looking for — markets, roles, locations, seniority — reads your CV, and saves your answers. After that, one command each morning:

> /job-run
