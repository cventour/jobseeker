Your job search,
remembered.

A job search falls apart in the gaps between apps. Applications live in ATS portals, recruiters reply by email, referrals arrive over WhatsApp, interviews land in a calendar. Nothing joins them up.

JobSeeker reads the channels you already use, keeps one honest picture of where everything stands, and each morning tells you the few things that actually need you. It runs entirely on your own machine.

Get it on GitHub How it works

The problem

  • An application goes quiet and you notice three weeks later.
  • Someone offers a referral in a chat. The CV never gets sent.
  • You apply to the same job twice, because it was reposted with a new reference number.
  • You find a great role, then lose it in a list of forty.
  • You agree a follow-up in one app and complete it in another, so it stays open forever.

Every morning

The only screen most days need.

What it never does

  • Never applies to a job without you approving that exact application.
  • Never sends a message without you approving that exact message.
  • Never opens your chat threads — opening marks them read and destroys your own signal.
  • Never logs private conversations — only threads with a job-search signal are recorded.
  • Never sends your data anywhere. Everything stays in files on your machine.

Getting started

Two commands.

git clone https://github.com/cventour/jobseeker
cd jobseeker && npm run setup

No dependencies to install — the whole system runs on Node built-ins and shell. Setup checks what you have, installs what it can, and verifies each permission actually worked.
